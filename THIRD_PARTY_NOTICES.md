# Üçüncü Taraf Bileşenleri

Bu proje ücretli tema, API veya bulut tarama hizmeti kullanmaz. Python bağımlılıkları `requirements.txt` dosyasında listelenmiştir.

- Django, WhiteNoise, python-dotenv
- ReportLab, OpenPyXL, QRCode, Pillow
- pywin32: Windows WIA cihaz erişimi için yalnızca Windows'ta kurulur

Her bileşen kendi açık kaynak lisansı altında kullanılır. Fiziksel tarama verisi internet hizmetine gönderilmez; yerel bilgisayarda işlenir.
